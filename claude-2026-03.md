# Odoo Agent Front - Claude Code Guide

## 📌 Project Overview
ChatGPT-style frontend for Odoo Agent.
**Core Tech:** Next.js 16 (App Router), React 19, Tailwind CSS v4, Framer Motion.
**Key Feature:** SSE (Server-Sent Events) streaming for real-time AI responses.

## 🛠 Tech Stack Details
- **Framework:** Next.js 16 + TypeScript.
- **Styling:** Tailwind CSS v4 (using `@theme` variables).
- **i18n:** `next-intl` (Locale-based routing: `/es`, `/en`, etc.).
- **Icons:** `lucide-react`.
- **Markdown:** `react-markdown` for agent response rendering.

## 📁 Project Structure & Conventions
- **App Router:** All routes inside `app/[locale]/`.
- **Components:** Functional components in `components/`, organized by domain (chat, pricing, odoo).
- **State Management:** - `use-chat.ts`: Handles SSE streaming logic and message history.
  - `use-odoo-config.tsx`: Context for Odoo credentials (stored in `localStorage`).
- **Translations:** JSON files in `messages/`. **Never hardcode strings**; use `useTranslations`.

## 📋 Development Rules (Token Saving)
- **SSE Focus:** When modifying chat, focus on `hooks/use-chat.ts` and `lib/api.ts`.
- **i18n Compliance:** Always check `messages/` before adding new keys. 126 keys per language.
- **Theme Variables:** Use CSS variables for colors (e.g., `var(--color-primary)`).
- **Strict Typing:** Always use interfaces from `lib/types.ts`.
- **Client vs Server:** Remember `'use client'` directive for components using hooks (framer-motion, state).

## 🔗 Backend Integration
- **Base URL:** `http://localhost:8000` (Default).
- **Streaming Endpoint:** `POST /chat/{id}/stream`.
- **Payload:** `{ message: string, odoo_config: OdooConfig, language: string }`.

## 🛠 Common Commands
- `npm run dev` - Start dev server.
- `npm run build` - Build for production.
- `npm run lint` - Check for errors.

## 🎨 UI Guidelines
- **Sidebar:** Collapsible, contains history grouped by date.
- **Messages:** Use `Markdown` component for responses.
- **Themes:** Support Light/Dark modes via CSS variables in `@theme`.
